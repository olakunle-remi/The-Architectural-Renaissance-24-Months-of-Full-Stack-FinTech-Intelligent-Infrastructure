### Day 2 (Today's Mission)

#### File and Directory Management

Learn:

* `touch`
* `cp`
* `mv`
* `rm`
* `cat`
* `nano`

Practice:

```bash
mkdir software_engineering
cd software_engineering

touch profile.txt
touch notes.txt

cp notes.txt backup_notes.txt

mv profile.txt myprofile.txt

cat myprofile.txt

nano myprofile.txt
```
